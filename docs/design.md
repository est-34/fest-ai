## 공통 표면

카드의 입체감은 공통 표면 그림자를 사용하며, 선택 표시는 선명한 안쪽 테두리로 구분한다. 번짐 없는 두꺼운 외곽 그림자는 사용하지 않는다.

둥근 곡면·밝은 안쪽 가장자리를 불투명하게 표현하고, 뉴모피즘의 입체감은 은은한 그림자로 표현한다. 카드·내비게이션·팝업·AI 대화 패널에는 반투명 배경과 배경 블러를 사용하지 않는다. 그림자·사진 틴트·모달 바깥 음영에는 투명도를 허용한다.

중립 회색 바탕, 불투명 카드, 진한 본문을 사용한다. 브랜드 파랑·ESG 초록과 시스템 한국어 글꼴은 유지한다. 형태·표면·그림자의 공통 값은 [토큰](../frontend/tokens.css), 테마와 접근성 모드의 적용은 [전역 스타일](../frontend/src/app/globals.css)이 원본이다.

## 구성과 조작

- 기존 방문객·운영자·상인 화면 구성과 정보 순서를 유지한다. 모바일 하단 메뉴는 안전 영역에서 띄운 캡슐로 표현하고 현재 메뉴는 색·채움·굵기로 구분한다.
- 카드 28px, 입력 18px, 대화상자 32px의 곡률을 사용하며 내비게이션은 필 형태로 표시한다. 작은 배지·아이콘은 기존 크기를 유지한다.
- 주요 버튼은 브랜드 채움과 약한 안쪽 밝기, 보조 버튼은 불투명 표면을 사용한다. 입력 경계와 즉시 표시되는 키보드 포커스를 제공한다.
- 다크·고대비·큰 글씨 모드를 유지한다. 모션 감소 설정에서는 장식 이동·확대 효과를 끈다. 그림자를 제거해도 선택·오류·포커스를 구분할 수 있어야 한다.

## 플로팅 필 탭 바

방문객 탭은 홈 → 지도 → AI 안내 → 예약 → ESG 순서로 배치한다. 키오스크 모드와 메뉴 설정에 따라 숨기는 항목은 기존 노출 규칙을 따른다.

하단 메뉴 외곽과 선택 배경은 완전한 필 곡률(999px)을 사용한다. 선택 배경은 아이콘과 라벨 전체를 감싸며, 모든 탭의 선택 아이콘·라벨 강조색은 브랜드 파랑(`primary`)으로 통일한다. 화면 가장자리·안전 영역과 간격을 두고 본문과 포커스를 가리지 않는다. 메뉴는 화면에 고정해 본문 위에 겹치며 별도 하단 배경 영역을 만들지 않는다. 스크롤 본문 안에 마지막 항목을 올려 볼 하단 여백을 두고, AI 안내의 입력 패널은 메뉴 위로 띄운다. 대화상자·카드의 곡률은 유지한다.

## 검증

일반 화면 테스트와 캡처는 데스크톱 가로 16:9(`1920×1080` CSS px), 모바일 세로 19.6:9(`360×784` CSS px, 높이:너비)를 기본 뷰포트로 통일한다. 크기는 브라우저 UI를 제외한 콘텐츠 영역 기준이다.

본문 넘침·하단 메뉴·긴 라벨·폼을 확인한다. 다크·고대비·큰 글씨·모션 감소 모드에서도 선택·오류·포커스를 구분한다. 기능 검증은 [검증 전략](../plan.md#검증-전략)을 따른다.

화면 캡처는 로컬 데모 데이터로 촬영하며 개인정보·비밀키가 보이지 않도록 한다. README에서 사용하는 캡처만 보관하고, 화면 구성 변경 시 해당 이미지를 갱신한다. 촬영 시 커밋·화면 크기·데이터 조건을 PR에 기록하며, 시각 검토는 기능 검증을 대신하지 않는다.
