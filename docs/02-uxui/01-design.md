## 공통 표면

공통 토큰은 [tokens.css](../../frontend/tokens.css), 테마·접근성 적용은 [globals.css](../../frontend/src/app/globals.css)가 원본이다.

- 중립 회색 바탕, 불투명 카드, 진한 본문, 브랜드 파랑·ESG 초록, 시스템 한국어 글꼴을 유지한다.
- 둥근 곡면·밝은 안쪽 가장자리와 은은한 뉴모피즘 표면 그림자를 사용하며 선택 표시는 선명한 안쪽 테두리로 구분한다(번짐 없는 두꺼운 외곽 그림자 금지).
- 카드·내비게이션·팝업·AI 대화 패널은 반투명 배경·블러를 쓰지 않으며 그림자·사진 틴트·모달 바깥 음영에만 투명도를 허용한다.

## 구성과 조작

- 역할별 구성을 유지하되 생성·관리가 경쟁하는 화면은 태스크 탭으로 분리한다. 모바일 하단 메뉴는 안전 영역 위 캡슐로 띄우고 현재 메뉴는 색·채움·굵기로 구분한다.
- 곡률: 카드 `28px`, 입력 `18px`, 대화상자 `32px`, 내비게이션 필 형태(작은 배지·아이콘은 기존 크기 유지).
- 주 버튼은 브랜드 채움·약한 안쪽 밝기, 보조 버튼은 불투명 표면을 사용하며 입력 경계와 즉시 표시되는 키보드 포커스를 제공한다.
- 다크·고대비·큰 글씨 모드와 모션 감소(장식 이동·확대 비활성화)를 지원하며 그림자 없이도 선택·오류·포커스를 구분한다.

## 플로팅 필 탭 바

방문객 탭은 `홈 → 지도 → AI 안내 → 예약 → ESG` 순으로 배치한다(키오스크·메뉴 설정 노출 규칙 유지). 외곽·선택 배경은 `999px` 필 곡률, 선택 강조색은 브랜드 파랑(`primary`)으로 통일한다. 별도 하단 배경 없이 화면 가장자리·안전 영역과 띄워 고정하고, 본문 하단 여백 확보 및 AI 입력 패널 상단 배치로 가림을 방지한다.

## 태스크와 복귀 경로

- 예약 화면은 프로그램 탐색과 내 예약을 탭으로 분리한다(예약 성공 시 내 예약 전환, 빈 내역에 탐색 버튼 제공, 제목 줄바꿈·인원/예약 조작 별도 줄 배치).
- 하단 메뉴에 없는 방문객 보조 화면은 히스토리와 무관하게 상위 화면으로 복귀한다(ESG 하위·스탬프 투어 → ESG, 기타 → 홈). 공통 빈 상태·오류 설명은 `14px` 이상으로 표시한다.
